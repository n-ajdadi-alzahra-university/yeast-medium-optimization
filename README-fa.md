# بهینه‌سازی محیط کشت مخمر با استفاده از یادگیری ماشین

این مخزن شامل کدهای پایتون مربوط به پروژه پایان‌نامه کارشناسی ارشد میکروبیولوژی صنعتی در گروه میکروبیولوژی، دانشکده علوم زیستی، دانشگاه الزهرا، تهران، ایران است.

**موضوع پروژه:** پیش‌بینی شاخص‌های رشد و بهینه‌سازی محیط کشت تعریف‌شده برای مخمر *Saccharomyces cerevisiae* با استفاده از داده‌های آزمایشگاهی، یادگیری ماشین و الگوریتم‌های بهینه‌سازی.

> **نکته انتشار:** پیش از عمومی کردن مخزن یا بازنشر داده‌های آزمایشگاهی، مجوزهای لازم از دانشگاه الزهرا را بررسی کنید. در تعهدنامه پایان‌نامه، انتشار و استفاده از دستاوردهای پایان‌نامه تابع مقررات دانشگاه و اخذ مجوز ذکر شده است.

## طراحی آزمایش و داده‌ها

مطابق پایان‌نامه، مجموعه داده نهایی شامل ۴۴ ترکیب منحصربه‌فرد محیط کشت بوده است: ۴۰ ترکیب تولیدشده با روش نمونه‌برداری ابرمکعب لاتین (LHS) با seed ثابت 123 و چهار ترکیب مرزی تکمیلی. برای هر ترکیب دو تکرار مستقل آزمایشگاهی انجام شد.

پنج متغیر اصلی ورودی و دامنه آن‌ها عبارت‌اند از:

| متغیر | فرمول شیمیایی | دامنه | واحد |
|---|---|---:|---|
| گلوکز | C₆H₁₂O₆ | 10–30 | g/L |
| سولفات آمونیوم | (NH₄)₂SO₄ | 2.5–7.5 | g/L |
| دی‌هیدروژن فسفات پتاسیم | KH₂PO₄ | 1.5–4.5 | g/L |
| سولفات منیزیم هفت‌آبه | MgSO₄·7H₂O | 0.25–0.75 | g/L |
| کلرید کلسیم دوآبه | CaCl₂·2H₂O | 2.25–6.75 | mg/L |

سایر اجزای محیط، از جمله ریزمغذی‌ها و ویتامین‌ها، در آزمایش‌ها به‌صورت ثابت و بر اساس فرمولاسیون محیط پایه وردیون حفظ شدند.

## متغیرهای پاسخ

- وزن خشک (g/L)
- تعداد سلول (cells/mL)
- جذب نوری در طول موج 600 نانومتر (OD600)
- وزن تر (g/L)

## روش‌های محاسباتی

شش مدل رگرسیونی برای هر چهار پاسخ مقایسه شدند: رگرسیون خطی، جنگل تصادفی، رگرسیون تقویت گرادیان، XGBoost، رگرسیون بردار پشتیبان و شبکه عصبی مصنوعی. ارزیابی با اعتبارسنجی متقاطع پنج‌تایی و معیارهای R²، MAE و RMSE انجام شد. در گزارش پایان‌نامه، رگرسیون خطی برای وزن خشک، تعداد سلول و وزن تر و جنگل تصادفی برای OD600 عملکرد بهتری داشتند.

اهمیت متغیرها با استفاده از ضرایب رگرسیون خطی و اهمیت ویژگی در مدل‌های مبتنی بر درخت بررسی شد. گلوکز در تحلیل گزارش‌شده برای هر چهار پاسخ، مهم‌ترین متغیر ورودی بود؛ این رتبه‌بندی به‌تنهایی اثبات‌کننده رابطه علت و معلولی نیست.

در مرحله بهینه‌سازی، الگوریتم PSO و بهینه‌سازی بیزی با استفاده از مدل پیش‌بیننده رگرسیون خطی مقایسه شدند. هر دو روش برای وزن خشک به ترکیب یکسانی رسیدند: گلوکز 30.00 g/L، سولفات آمونیوم 7.50 g/L، KH₂PO₄ برابر 4.50 g/L، MgSO₄·7H₂O برابر 0.75 g/L و CaCl₂·2H₂O برابر 6.75 mg/L. وزن خشک پیش‌بینی‌شده 14.753 g/L و میانگین آزمایشگاهی آن در دو تکرار 14.840 g/L گزارش شد؛ اختلاف مطلق حدود 0.087 g/L و خطای نسبی حدود 0.59 درصد بود.

## محیط نرم‌افزاری

پایان‌نامه Python 3.8 و نسخه‌های زیر را گزارش می‌کند: NumPy 1.24.4، pandas 2.0.3، Matplotlib 3.7.5، Seaborn 0.13.2، SciPy 1.10.1، scikit-learn 1.3.2 و openpyxl 3.1.5. نسخه دقیق XGBoost و کتابخانه مورد استفاده برای پیاده‌سازی بهینه‌سازی بیزی در متن پایان‌نامه مشخص نشده است؛ برای بازتولید دقیق نتایج، این نسخه‌ها باید از محیط کاری اصلی بررسی شوند.

## اجرا

ابتدا محیط مجازی ایجاد و فعال شود و سپس وابستگی‌ها نصب شوند:

```bash
python -m venv .venv
```

در ویندوز:

```powershell
.venv\Scripts\activate
```

نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

پیش از اجرا، مسیر فایل اکسل و پوشه‌های خروجی در هر کد را با ساختار واقعی مخزن بررسی کنید. نام فایل‌ها و پوشه‌های نمونه در README انگلیسی باید با نام‌های واقعی مخزن یکسان بمانند.
