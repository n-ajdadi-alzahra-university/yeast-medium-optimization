# بهینه‌سازی محیط کشت مخمر با استفاده از یادگیری ماشین

این مخزن شامل کدهای پایتون توسعه‌یافته برای پایان‌نامه کارشناسی ارشد میکروبیولوژی صنعتی در گروه میکروبیولوژی، دانشکده علوم زیستی، دانشگاه الزهرا، تهران، ایران است.

**موضوع پروژه:** پیش‌بینی شاخص‌های رشد و بهینه‌سازی محیط کشت تعریف‌شده برای مخمر *Saccharomyces cerevisiae* با استفاده از داده‌های آزمایشگاهی، یادگیری ماشین و الگوریتم‌های بهینه‌سازی.

> **نکته انتشار:** پیش از عمومی کردن این مخزن یا بازنشر داده‌های آزمایشگاهی، الزامات مربوط را بررسی کرده و مجوزهای لازم از دانشگاه الزهرا و استادان راهنمای مرتبط را دریافت کنید.

## معرفی پروژه

در این مطالعه، **۴۴ ترکیب منحصربه‌فرد محیط کشت** برای مخمر *Saccharomyces cerevisiae* بررسی شد. طراحی آزمایش شامل ۴۰ ترکیب تولیدشده با روش نمونه‌برداری ابرمکعب لاتین (LHS) با بذر تصادفی ثابت 123 و چهار ترکیب مرزی تکمیلی بود.

هر ترکیب با دو تکرار مستقل آزمایشگاهی بررسی شد. داده‌های حاصل برای توسعه و ارزیابی مدل‌های یادگیری ماشین به‌منظور پیش‌بینی چهار شاخص رشد استفاده شدند.

پنج جزء محیط کشت به‌عنوان متغیرهای ورودی در نظر گرفته شدند. سایر اجزای محیط کشت تعریف‌شده بر پایه فرمولاسیون وردیون، از جمله عناصر کم‌مقدار و ویتامین‌ها، مطابق فرمولاسیون آزمایشی ثابت نگه داشته شدند.

## متغیرهای ورودی

| متغیر ورودی             | فرمول شیمیایی |     دامنه | واحد |
| ----------------------- | ------------- | --------: | ---- |
| گلوکز                   | C₆H₁₂O₆       |     10–30 | g/L  |
| سولفات آمونیوم          | (NH₄)₂SO₄     |   2.5–7.5 | g/L  |
| دی‌هیدروژن فسفات پتاسیم | KH₂PO₄        |   1.5–4.5 | g/L  |
| سولفات منیزیم هفت‌آبه   | MgSO₄·7H₂O    | 0.25–0.75 | g/L  |
| کلرید کلسیم دوآبه       | CaCl₂·2H₂O    | 2.25–6.75 | mg/L |

## شاخص‌های رشد

چهار متغیر پاسخ برای توسعه و ارزیابی مدل‌ها استفاده شدند:

* **وزن خشک** (g/L)
* **تعداد سلول** (cells/mL)
* **جذب نوری در طول موج ۶۰۰ نانومتر** (OD600)
* **وزن تر** (g/L)

## روش‌ها

### ۱. طراحی آزمایش

* تولید ۴۰ نقطه طراحی با استفاده از روش نمونه‌برداری ابرمکعب لاتین (LHS).
* استفاده از بذر تصادفی ثابت `123` برای طراحی LHS.
* افزودن چهار ترکیب تکمیلی برای پوشش نقاط مرزی.
* بررسی هر ترکیب با دو تکرار مستقل آزمایشگاهی.

### ۲. تحلیل داده‌ها و پیش‌پردازش

روند تحلیل داده‌ها شامل آمار توصیفی، هیستوگرام‌ها، نمودارهای پراکندگی، تحلیل همبستگی و استانداردسازی متغیرهای ورودی در موارد لازم بود.

برای استانداردسازی در روندهای یادگیری ماشین مربوط، از `StandardScaler` در کتابخانه scikit-learn استفاده شد.

### ۳. مدل‌های یادگیری ماشین

شش الگوریتم رگرسیونی برای چهار شاخص رشد مقایسه شدند:

۱. رگرسیون خطی (LR)

۲. جنگل تصادفی (RF)

۳. رگرسیون تقویت گرادیان (GBR)

۴. الگوریتم تقویت گرادیانی(XGBoost)

۵. رگرسیون بردار پشتیبان (SVR)

۶. شبکه عصبی مصنوعی (ANN)

عملکرد مدل‌ها با استفاده از **اعتبارسنجی متقاطع پنج‌تایی** و معیارهای زیر ارزیابی شد:

* ضریب تعیین (R²)
* میانگین قدرمطلق خطا (MAE)
* جذر میانگین مربعات خطا (RMSE)

بر اساس نتایج گزارش‌شده در پایان‌نامه، رگرسیون خطی برای وزن خشک، تعداد سلول و وزن تر و جنگل تصادفی برای OD600 عملکرد بهتری داشتند.

### ۴. اهمیت متغیرهای ورودی

اهمیت متغیرهای ورودی با استفاده از ضرایب رگرسیون خطی و معیارهای اهمیت ویژگی در مدل‌های مبتنی بر درخت، شامل جنگل تصادفی، تقویت گرادیان و XGBoost، بررسی شد.

در تحلیل‌های گزارش‌شده، گلوکز برای هر چهار شاخص رشد به‌عنوان مهم‌ترین متغیر ورودی شناسایی شد. این رتبه‌بندی مبتنی بر مدل به‌تنهایی نباید به‌عنوان اثبات رابطه علت و معلولی زیستی تفسیر شود.

### ۵. بهینه‌سازی

الگوریتم بهینه‌سازی ازدحام ذرات (PSO) و بهینه‌سازی بیزی (Bayesian Optimization) با استفاده از رگرسیون خطی به‌عنوان مدل پیش‌بیننده در تحلیل‌های بهینه‌سازی پایان‌نامه مقایسه شدند.

هر دو روش در محدوده متغیرهای بررسی‌شده، ترکیب بهینه پیش‌بینی‌شده یکسانی برای وزن خشک و همچنین ترکیب بهینه پیش‌بینی‌شده یکسانی برای تعداد سلول شناسایی کردند.

#### ترکیب بهینه پیش‌بینی‌شده برای وزن خشک

| جزء محیط کشت             | غلظت بهینه پیش‌بینی‌شده |
| ------------------------ | ----------------------: |
| گلوکز                    |               30.00 g/L |
| سولفات آمونیوم           |                7.50 g/L |
| KH₂PO₄                   |                4.50 g/L |
| MgSO₄·7H₂O               |                0.75 g/L |
| CaCl₂·2H₂O               |               6.75 mg/L |
| **وزن خشک پیش‌بینی‌شده** |          **14.753 g/L** |

ترکیب بهینه با استفاده از دو تکرار آزمایشگاهی ارزیابی شد و میانگین وزن خشک اندازه‌گیری‌شده برابر با **14.840 g/L** بود.

اختلاف مطلق میان مقدار پیش‌بینی‌شده و میانگین آزمایشگاهی حدود **0.087 g/L** و خطای نسبی حدود **0.59 درصد** بود.

این نتایج، مقادیر بهینه پیش‌بینی‌شده توسط مدل را در محدوده‌های بررسی‌شده نشان می‌دهند و اثبات‌کننده وجود یک نقطه بهینه سراسری در خارج از این محدوده‌ها نیستند.

## ساختار مخزن
ساختار پوشه‌ها و فایل‌های این پروژه در ادامه آمده است.

```text
yeast-medium-optimization/
├── data/
├── experimental-design/
├── model-training-evaluation/
├── feature-importance/
├── pso-optimization/
├── bayesian-optimization/
├── README.md
├── README-fa.md
├── requirements.txt
├── .gitignore

```

`data/`: فایل‌های مجموعه داده آزمایشگاهی، مشروط به مجوزهای انتشار مربوط.

* `experimental-design/`: اسکریپت‌های تولید طراحی LHS و ترکیب‌های مرزی تکمیلی.
* `model-training-evaluation/`: اسکریپت‌های آموزش و مقایسه شش مدل رگرسیونی برای چهار شاخص رشد.
* `feature-importance/`: اسکریپت‌های تحلیل اهمیت نسبی متغیرهای ورودی.
* `pso-optimization/`: اسکریپت‌های بهینه‌سازی با الگوریتم ازدحام ذرات.
* `bayesian-optimization/`: اسکریپت‌های مربوط به بهینه‌سازی بیزی.

## نصب و اجرا

ابتدا یک محیط مجازی پایتون ایجاد و فعال کنید.

**ویندوز (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\activate
```

**macOS یا Linux:**

```bash
python -m venv .venv
source .venv/bin/activate
```

سپس وابستگی‌های درج‌شده در فایل `requirements.txt` را نصب کنید:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

پیش از اجرای اسکریپت‌ها، مسیر مجموعه داده، پوشه خروجی و وابستگی‌های نصب‌شده را با ساختار فعلی مخزن تطبیق دهید.

## بازتولید نتایج

* برای تولید ۴۰ نقطه طراحی LHS از بذر تصادفی ثابت `123` استفاده شد.
* چهار ترکیب مرزی تکمیلی به طراحی اضافه شد و در مجموع ۴۴ ترکیب منحصربه‌فرد محیط کشت به دست آمد.
* هر ترکیب با دو تکرار مستقل آزمایشگاهی بررسی شد.
* ارزیابی مدل‌ها با اعتبارسنجی متقاطع پنج‌تایی انجام شد.

* غلظت‌های بهینه و مقادیر پیش‌بینی‌شده باید در محدوده تعریف‌شده آزمایش‌ها و با توجه به محدودیت‌های مجموعه داده تفسیر شوند.

برای بازتولید تحلیل‌های گزارش‌شده، از نسخه نهایی اسکریپت‌ها و مجموعه داده مرتبط با پایان‌نامه استفاده کنید.
